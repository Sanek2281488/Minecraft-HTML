Описание:
Это майнкрафт,сделанный с нуля спомощью ии.В нём есть блоки,предметы,бесконечная генерация,печки,сундуки,верстаки,мобы и т.д
Приятной игры!

Как играть:
Скачай архив или релиз, там находится файл minecraft.html, открой его, откроется браузер и можешь играть.

Как запустить сервер:
Чтобы запустить сервер, нужно скачать node.js с сайта, затем в папке игры запустить server.bat, там откроется терминал с айпи
игроки заходят с айпи и порт 3000, а сам хост, заходит с localhost:3000, ну и всё
